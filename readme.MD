# 🕶️ SPECTACLE WEBSITE

A modern, responsive optical store web application built using **React**, **Firebase**, and **Tailwind CSS**. The website is designed to provide customers with a seamless eyewear shopping experience while enabling store owners to manage products through an easy-to-use admin panel.



---

## ✨ Features

### Customer Side

- 🏠 Modern and responsive homepage
- 👓 Browse premium spectacles and sunglasses
- 🔍 Filter products by gender and category
- 📄 Detailed product pages
- 💬 WhatsApp enquiry for products
- 👁️ Eye test booking page
- 📱 Fully responsive across all devices
- ⚡ Smooth animations and premium UI

### Admin Panel

- 🔐 Secure admin login
- ➕ Add new products
- ✏️ Edit existing products
- ❌ Delete products
- ⭐ Mark products as featured
- ☁️ Firebase Firestore integration

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/new-optiworld.git
```

### Navigate to the Project

```bash
cd new-optiworld
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

---

## 🔥 Firebase Setup

1. Create a Firebase project.
2. Enable **Cloud Firestore**.
3. Enable **Firebase Authentication**.
4. Add your Firebase configuration in:

```
src/firebase/firebase.js
```
